13 · Design Token Reference

How to add a new theme
/* 1. Copy themes/theme-light.css → themes/theme-yourname.css */ /* 2. Change the selector: */ [data-theme="yourname"] { /* override any tokens */ --color-primary: #your-color; --color-bg: #your-bg; } /* 3. Link the new file and add a toggle button to the theme bar. */
Available Token Groups
/* Colors */ --color-primary --color-success --color-warning --color-error --color-info --color-accent --color-text --color-border --color-surface --color-bg
/* Layout & UI */ --header-bg --sidebar-bg --modal-bg --tooltip-bg --panel-bg --chip-bg --shadow-sm ... --shadow-xl --radius-sm ... --radius-full
