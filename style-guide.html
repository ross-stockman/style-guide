13 · Design Token Reference

How to add a new theme
/* 1. Copy themes/theme-light.css → themes/theme-yourname.css */ /* 2. Change the selector: */ [data-theme="yourname"] { /* override any tokens */ --color-primary: #your-color; --color-bg: #your-bg; /* ... etc */ } /* 3. Link the new file in style-guide.html: */ <link rel="stylesheet" href="themes/theme-yourname.css"> /* 4. Add a toggle button to the .theme-bar: */ <button class="theme-btn" data-theme="yourname">🎨 Your Theme</button> /* That's it — no other code changes needed. */
